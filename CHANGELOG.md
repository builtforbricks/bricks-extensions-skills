# Changelog

Each release of this pack names the Bricks Extensions version it was checked against (`verifiedUpTo` in
`skills/bxt-update/references/index.json`). Skills and plugin are released together; a pack never describes a
plugin that has not shipped.

## 0.1.0, 2026-10-12

Pre-release, verified up to Bricks Extensions 1.0.0-rc.2. It goes out with Bricks Extensions 1.0.0.

- First pack: `bxt-start-here`, `bxt-static-export`, `bxt-preflight-findings`, `bxt-forms-routes`,
  `bxt-github-deploy`, `bxt-breakpoint-canvas` and `bxt-update`.
- Brought up to the release candidate: the infinite canvas in `bxt-breakpoint-canvas`; the header probe's cases, the
  Woo, language and JSON-with-a-file rows in `bxt-preflight-findings`; caches, the link safety net, languages and the
  Woo catalogue in `bxt-static-export`; popups, loops, components, file fields and `{{field}}` tokens in
  `bxt-forms-routes`.
